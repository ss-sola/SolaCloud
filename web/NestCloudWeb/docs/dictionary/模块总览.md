# dictionary 模块总览

## 模块职责

`dictionary` 页面负责维护字典命名空间下的字典聚合，并在编辑字典弹窗内继续维护该字典下的字典项与批量导入操作。

## 当前实现

- `src/modules/system/pages/DictionaryPage.tsx` 使用旧版同源的 `dictionary-split-layout` 紧凑卡片结构展示当前命名空间下的字典列表。
- 页面主体只保留字典聚合列表；字典项不再作为独立页面卡片展示，而是跟随“编辑字典”弹窗一并维护。
- `src/modules/system/api/dictionaryApi.ts` 统一封装总览、命名空间、字典聚合、字典项和批量导入接口。
- `src/modules/system/hooks/usePageTableState.ts` 负责字典聚合列表的分页状态，以及弹窗内字典项列表的排序状态。
- `src/modules/system/components/ModalDialog.tsx` 负责字典编辑、字典项编辑和导入弹窗承载。

## 关键规则

- 页面进入后先加载总览和命名空间，再按当前命名空间加载字典聚合分页列表。
- 点击字典行只负责高亮当前聚合；字典项维护入口统一收口在“编辑”弹窗内。
- 新增字典时弹窗只展示聚合表单；编辑已有字典时会额外展示字典项列表、刷新、新增字典项和批量导入区域。
- 字典项列表直接在字典编辑弹窗内展示当前字典下的全部数据，不显示分页控件，但保留按字段排序能力。
