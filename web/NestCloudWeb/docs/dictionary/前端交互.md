# dictionary 前端交互

## 页面入口

- 运行时菜单组件标识为 `dictionary`。
- 页面进入后会并行请求字典总览和命名空间列表，再按当前命名空间加载字典聚合分页列表。

## 顶部动作

- `刷新字典`：重新拉取总览、命名空间、字典聚合和当前字典项查询。
- `新增字典`：打开新增字典弹窗。
- 顶部信息条展示服务名、能力数和当前页说明。

## 字典列表区

- 页面主体使用 `dictionary-split-layout` 紧凑卡片布局，只展示“字典列表”卡片。
- 卡片内提供命名空间下拉，切换后会重置当前选中字典和分页状态。
- 列表展示字典名称、状态、字典项数量、描述、更新时间和操作。
- 点击行会高亮当前字典，但不会直接在页面主区展开字典项列表。

## 字典编辑弹窗

- `新增字典` 时只展示聚合表单，包含命名空间、字典编码、中文名称、描述和状态。
- 字典新增/编辑弹窗使用加宽弹窗，避免聚合表单和字典项维护区域过窄。
- 长内容场景下，弹窗滚动条保持在弹窗内部，避免页面外层跟随滚动。
- `编辑` 已有字典时，弹窗下半区会显示“字典项列表”，并提供 `刷新`、`新增字典项`、`批量导入` 操作。
- 弹窗内字典项列表直接展示当前字典下的全部字典项，保留按 Key、更新时间排序，不显示分页和每页条数切换。

## 字典项与导入

- `新增字典项` / `编辑` 会打开独立字典项弹窗，维护命名空间、字典编码、字典项编码、中文名称、描述、字典值和状态。
- `批量导入` 会打开导入弹窗，提交命名空间、中文名称、描述和 `Items(JSON 数组)`。
- 字典项保存、删除、导入成功后，会同步刷新字典聚合列表和当前弹窗内字典项列表。

## 交互反馈

- 页面顶部统一显示成功/失败提示，如“字典保存成功”“字典项删除成功”。
- 字典聚合列表为空时显示“暂无字典数据”。
- 编辑弹窗内字典项列表为空时显示“暂无字典项数据”。
