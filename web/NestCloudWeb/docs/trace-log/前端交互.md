# 集中日志查询

管理员从「运行与审计 → 集中日志查询」打开 `/system/trace-log`。粘贴响应头 `x-trace-id` 的值后点击「查询」或按 Enter。页面通过统一网关查询最近 24 小时内的日志。

结果将入口网关放在首行，请求完成记录按调用开始时间展示，普通和历史日志沿用写入时间。桌面端按列排列，手机端每条日志显示为一张卡片。列表只包含预览，展开单条时通过网关加载完整日志及堆栈。收起后释放原文。地址缺失时显示实例标识。网关记录了转发目标且结果中缺少该实例日志时，页面单独提示，静态转发可按目标地址关联。超过 500 条优先保留网关和接单结果。时间采用浏览器时区。
