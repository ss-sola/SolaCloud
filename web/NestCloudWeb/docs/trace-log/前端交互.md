# 集中日志查询

管理员从「运行与审计 → 集中日志查询」打开 `/system/trace-log`。粘贴响应头 `x-trace-id` 的值后点击「查询」或按 Enter。页面通过统一网关查询最近 24 小时内的日志。

结果使用单张 SVG 绘制自上而下的调用流程。画布采用深色点阵，网格随平移和缩放移动。父调用在上，同级调用从左到右。节点标题栏显示网关或服务、名称及 HTTP 状态，2xx 使用绿色标签，错误使用红色标签。缺少 HTTP 状态时显示日志级别。节点中部显示请求和实际实例地址，底部显示时间、级别和耗时。

连线沿三次贝塞尔曲线连接上下端口。相邻两层的短连线显示一束青白流光，亮芯指示方向，拖尾沿途渐隐，每程约 1.7 秒。较长的分支分别显示两束或三束错峰流光，每程约 2.2 或 2.8 秒。SVG 动画直接引用连线路径。HTTP 304 与其他正常返回使用相同光效，错误连线使用半速红光。动画展示已采集的调用关系。悬停提亮连线，选中节点时高亮直接关联的连线。系统开启减少动态效果时保留静态连线、端口和状态颜色。视觉实现参照 [test-cloud 工作流画布](https://github.com/ss-sola/test-cloud/blob/797ee0813b784d61ac5d81bc26552409d6cae910/apps/system-service/public/css/workflow.css)。

可放大、缩小、恢复实际大小或适应窗口。鼠标使用手形光标拖动平移，滚轮围绕指针位置缩放。触屏可单指拖动、双指围绕触点中点缩放。流程图获得键盘焦点时可用方向键平移。拖动和捏合不会打开节点详情，缩放时节点文字保持矢量渲染。

点击节点后，在弹窗中按需加载该次调用的脱敏 HTTP 详情。“日志原文”可以展开同一条记录的完整内容。关闭按钮和 Escape 均可关闭弹窗。同一 span 的其他日志可独立展开查看，异常可查看堆栈。历史或缺少父级信息的节点独立显示，已有明确目标的网关历史日志可按唯一实例关联。超过 500 条优先保留网关和服务处理结果。时间采用浏览器时区。
