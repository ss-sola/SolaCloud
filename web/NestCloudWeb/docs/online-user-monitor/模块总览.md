# online-user-monitor 模块总览

## 模块职责

`online-user-monitor` 页面负责展示当前在线会话列表，并提供管理员手动踢下线能力。

## 当前实现

- `src/modules/system/api/monitorApi.ts` 同时封装在线用户分页查询和踢人下线接口。
- `src/modules/system/pages/OnlineUserMonitorPage.tsx` 负责筛选表单、表格、分页和下线交互。
- `src/modules/system/hooks/usePageTableState.ts` 负责分页与排序状态。
- `src/modules/system/components/PagePagination.tsx` 负责列表分页操作。

## 关键数据

- 在线用户记录包含账号、显示名、头像、IP、UA、登录时间、最近活跃时间和过期时间。
- 页面顶部信息条继续展示服务名和能力数。
