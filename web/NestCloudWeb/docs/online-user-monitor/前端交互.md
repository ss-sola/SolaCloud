# online-user-monitor 前端交互

## 页面入口

- 运行时菜单组件标识为 `online-user-monitor`。
- 页面进入后会并行请求监控总览与在线用户分页列表。

## 顶部动作

- `刷新在线用户`：重新拉取顶部概览和当前分页数据。
- 顶部信息条展示服务名、在线用户数和当前页说明。

## 列表筛选

- 关键词输入框支持按账号名、显示名、IP 和 User-Agent 模糊筛选。
- `查询` 会重置到第一页并按当前筛选条件重新拉取列表。
- `重置` 会清空关键词并回到第一页。

## 表格操作

- 表格展示头像、账号、IP、登录时间、最近活跃时间、过期时间和 User-Agent。
- `踢人下线` 点击后先弹出确认框；确认后调用下线接口。
- 下线成功后页面提示“已踢下线”，并刷新列表与顶部在线人数。

## 交互反馈

- 请求失败时展示“在线用户监控加载失败”或“踢人下线失败”。
- 列表为空时显示“暂无在线用户数据”。
- 分页区支持切页和修改每页条数。
