# notification 模块总览

## 模块职责

`notification` 页面负责统一承载公告管理和站内信管理，并展示当前登录账号的通知运行态，包括运行中公告、站内信运行态列表和未读数。

## 当前实现

- `src/modules/system/api/notificationApi.ts` 统一封装公告与站内信相关接口，包括总览、列表、详情、运行态、发送、已读和全部已读。
- `src/modules/system/pages/NotificationPage.tsx` 负责公告列表、站内信列表、运行态预览区和两个弹窗表单。
- `src/modules/system/api/accountApi.ts` 提供 `/api/system/accounts/options` 轻量账号选项列表，用于站内信接收人选择、广播数量提示和消息发送记录名称展示。
- `src/modules/system/api/dictionaryApi.ts` 提供公告发布状态、站内信已读状态和发送模式字典。
- `src/modules/system/hooks/usePageTableState.ts` 负责公告列表与站内信列表的分页与排序状态。

## 关键数据

- `NotificationOverviewResponse` 返回服务名、能力列表、公告总数和站内信总数。
- `AnnouncementItem` 包含标题、内容、发布状态、生效时间、发布时间、撤回时间和发布人信息。
- `StationMessageItem` 包含标题、内容、接收账号、发送账号、已读状态和读取时间。
- 运行态公告只展示已发布且在生效期内的公告；运行态站内信、未读数、已读操作只针对当前登录账号。
