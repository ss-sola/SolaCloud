# 主题切换

## 概述

NestCloud 前端系统管理台与 RAG 模块支持三套主题切换：浅绿（默认）、深蓝、暗黑。主题通过 `data-theme` attribute 切换，状态持久化到 localStorage。

## 三套主题

RAG 模块使用独立的 `--rag-*` 变量集，同样分为三套主题覆盖。

## API

### themeStore（Zustand Store）

位置：`src/shared/state/themeStore.ts`

```ts
import { useThemeStore, THEMES } from '@/shared/state/themeStore';

// 当前主题
const theme = useThemeStore((s) => s.theme);

// 主题列表
const themes = useThemeStore((s) => s.themes); // ['light', 'dark', 'abyss']

// 切换主题
useThemeStore.getState().setTheme('dark');
```

### useTheme Hook

位置：`src/shared/hooks/useTheme.ts`

```ts
import { useTheme } from '@/shared/hooks/useTheme';

function MyComponent() {
  const { theme, themes, setTheme } = useTheme();
  return <button onClick={() => setTheme('abyss')}>{theme}</button>;
}
```

### THEMES 常量

```ts
export const THEMES = ['light', 'dark', 'abyss'] as const;
export type Theme = (typeof THEMES)[number];
```

## 主题切换机制

1. `index.html` 中的内联脚本在 React 渲染前从 localStorage 读取主题并设置 `data-theme`，防止闪烁。
2. React 初始化时 `themeStore` 再次读取 localStorage 并同步 `document.documentElement.dataset.theme`。
3. 调用 `setTheme` 时，同步更新 `data-theme` attribute 和 localStorage。
4. CSS 通过 `:root[data-theme="dark"]` 和 `:root[data-theme="abyss"]` 覆盖变量值，所有组件自动响应。

## 为新组件添加主题支持

### 系统管理台组件

直接使用 `var(--system-*)` 变量即可，变量定义在 `legacy-style.css` 中。

### RAG 组件

使用 `var(--rag-*)` 变量，变量定义在 `global.css` 中。CSS Module 文件通过全局 CSS 变量响应主题，无需额外处理。

### 新增主题 Token

1. 在 `legacy-style.css` 的 `:root` 中添加默认值。
2. 在 `:root[data-theme="dark"]` 和 `:root[data-theme="abyss"]` 中添加对应覆盖值。
3. 如有 RAG 专用变量，在 `global.css` 中同步添加 `--rag-*` 定义。

## 限制与注意事项

- `data-theme` attribute 设置在 `html` 元素上。
- 主题状态仅存储在 localStorage，不涉及后端。
- Bootstrap 组件的样式优先级较高，主题变量需在 Bootstrap 之后加载（legacy-style.css 在 Bootstrap 之后引入）。
