# 主题切换

管理台顶栏的日月图标开关即时切换外观。初次访问使用浅绿。浏览器会在刷新和下次访问时恢复上次选择。旧版的深蓝和暗黑偏好都沿用新的深色外观。

## 控件配色

| 用途 | 浅绿 | 深色 |
| --- | --- | --- |
| 画布 | `#edf2f7` | `#0d1219` |
| 卡片、表单、弹窗 | `#ffffff` | `#19212d` |
| 强调色 | `#22a06b` | `#85afe8` |
| 选中项底色 | `#dff3ea` | `#263143` |
| 正文 | `#1f2937` | `#e4eaf3` |
| 次要说明 | `#6b7280` | `#abb8ca` |

深色主题使用集中日志流程图的共享色板。蓝色用于交互，成功和失败状态沿用流程图的绿、红配色。流程图画布在两种主题下都使用自身的深色配色。

深色模式下，侧边栏、菜单管理列表、编辑预览和图标选择器中的单色菜单图标显示为白色。内联操作图标随控件文字颜色切换。

## 首次绘制与持久化

1. `index.html` 在 React 启动前读取 `localStorage.theme`。已保存的 `dark` 和 `abyss` 映射到深色，并将旧值 `abyss` 更新为 `dark`。未知或缺失的值使用浅绿。
2. `themeStore` 从根元素读取首次绘制的结果。`useTheme().setTheme('light' | 'dark')` 切换时同步更新 `data-theme`、Bootstrap 的 `data-bs-theme` 以及本地偏好。浏览器限制存储时，当前页仍可正常切换。
3. 系统页面消费 `--system-*` 变量，RAG 消费 `--rag-*` 变量。深色画布、面板、文字和强调色均来自 `global.css` 的 `--wf-*` 流程图色板。Bootstrap 表格、表单、模态框随主题一起切换。
