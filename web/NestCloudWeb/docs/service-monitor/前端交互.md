# service-monitor 前端交互

## 页面入口

- 运行时菜单组件标识为 `service-monitor`。
- 页面进入后会并行请求监控总览和服务指标数据。

## 顶部动作

- `刷新服务监控`：重新拉取总览与服务监控指标。
- 顶部信息条展示服务名、能力数和当前页说明。

## 页面展示

- 页面只读，不提供新增、编辑、删除或弹窗操作。
- CPU、内存、磁盘空间、服务器信息分别以指标卡形式展示。
- 磁盘不可用时，页面改为展示路径、状态和错误信息。

## 交互反馈

- 首次加载且尚无数据时显示“服务监控数据加载中...”。
- 任一请求失败时展示统一错误提示“服务监控加载失败”。
- 刷新过程中按钮会根据查询状态禁用，避免重复提交。
