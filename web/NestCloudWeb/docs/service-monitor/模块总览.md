# service-monitor 模块总览

## 模块职责

`service-monitor` 页面负责展示系统服务的运行时指标，覆盖 CPU、内存、磁盘和服务进程信息。该页只读，不承担写操作。

## 当前实现

- `src/modules/system/api/monitorApi.ts` 统一封装 `/api/system/monitors/overview` 与 `/api/system/monitors/service`。
- `src/modules/system/pages/ServiceMonitorPage.tsx` 负责页面渲染、顶部动作和指标卡展示。
- `src/modules/system/pages/SystemPageFrameContext.tsx` 负责顶部动作、服务名和能力数信息条。
- `src/modules/system/utils/formatters.ts` 负责时间格式化。

## 关键数据

- `overview`：服务名、能力列表、在线人数概览。
- `service metrics`：CPU 模型与负载、内存使用、磁盘容量、Node 进程与主机信息。
