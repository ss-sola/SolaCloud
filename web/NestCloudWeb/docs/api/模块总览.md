# 前端 API 连接

浏览器通过 `ApiClient.buildUrl` 生成网关 URL。常规 JSON 请求、文件上传的检查、分片、合并以及 RAG 聊天 SSE 使用此地址，并发送会话 Cookie。上传配置中的相对路径使用网关 origin，显式配置的完整上传地址沿用其自身 origin。下载和预览读取文件服务返回的资源 URL。

本地打开 `http://localhost:5173` 时，API 请求发往 `http://localhost:3100`。通过 `127.0.0.1` 打开前端时，API 也使用 `127.0.0.1`，以保持两端处在同一站点。Vite 开发与预览服务器提供页面和资源。

部署时，在前端构建环境设置 `VITE_GATEWAY_ORIGIN`，值为公开网关的 HTTP(S) origin，例如 `https://api.example.com`。同时把前端页面的 origin 加入网关的 `GatewayAllowedOrigins`，例如 `https://admin.example.com`。使用同一站点的 HTTPS 域名可沿用默认 `SameSite=Lax` 会话配置。变更前端的网关地址后需要重新构建前端产物。
