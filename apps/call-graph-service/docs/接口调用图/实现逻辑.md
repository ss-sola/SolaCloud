# 实现逻辑

扫描器先检查项目入口的导入、项目依赖及框架配置。依据不足时，再检查业务源码中的框架导入。若仍有多个候选或无法识别，返回提示。整个发现过程仅读取文件。

Koa 策略解析路由声明、路由别名、参数化注册和微助教的目录挂载。NestJS 策略从应用模块追踪已注册的控制器，将全局前缀、模块路径、控制器路径与 HTTP 方法装饰器组合为接口。可静态解析的常量和依赖注入服务会参与建图，动态声明无法展开时返回提示。两种策略共用方法调用图解析，每个方法以项目相对文件名和源码中的 UTF-16 偏移标识。修改源码后应重新扫描。

静态图包含可解析的调用分支，最多 1200 个节点、4800 条边，达到边界时返回提示。页面可展开静态分析之外实际执行的方法。当前请求的采集范围是目标进程内的项目源码。

分析器和探针共享源码命名规则，为静态节点与方法进入事件写入 `anonymous`。匿名节点仍参与入口匹配和父子调用采集。画布折叠它们时，静态图追踪到最近可见方法，运行图按同一请求的 `callId` 和 `parentId` 追踪到最近可见祖先。这样重复调用同一回调的不同分支可以分别着色。

`computationOnly` 按方法体和传递调用关系计算。分析器识别常见字符串、数值、集合和日期同步运算，从可确认的叶子向调用者传播。存在数据库或网络调用、异步等待、Promise、定时器、未识别的依赖或动态调用时会保留对应方法及其调用者。循环依赖以及超出分析上限的路径也保留。实例方法、静态方法及模块函数使用同一套规则。服务依据本次扫描的源码节点标识为探针事件补上相同标记，运行时才发现的方法保持可见。

目标作为独立子进程运行。启动项目时，分析线程只解析已注册的处理器入口，通过 IPC 将路由模板与入口节点交给子进程。选择接口后才展开静态调用链并缓存该图的计算标记。预加载器在模块加载阶段插桩，通过 HTTP 方法、实际路径和可用的 Koa 匹配模板识别接口，从处理器入口开始采集。控制器之前执行的全局项目中间件不混入方法记录。AsyncLocalStorage 将每次调用关联到父调用和请求。动态路径、方法覆写、异步返回值及异常按实际执行采集。Koa 处理器返回 undefined 时还记录其响应正文。快照对常见敏感字段名脱敏，并限制深度、集合大小和字符串长度。请求的自由文本可能包含业务数据，调试权限应仅授予需要的账号。

Koa 探针在源码载入时采集，NestJS 探针启动项目内编译好的 JavaScript，在内存中通过 source map 把可验证的执行位置映射回 TypeScript。缺少映射、源码与构建不一致或指向项目外部时，对应方法跳过采集并提示，其他可映射的方法继续记录。

每次启动探针时，调用图服务使用当前登录会话从 system-service 读取 `system / api_call_graph_probe` 的启用字典项。两项额度接受非负安全整数，0 代表该项不限量。项目会话全程使用启动时的配置，切换接口沿用该配置。

| 字典键 | 默认值 | 计数范围 |
| --- | ---: | --- |
| `maxCallsPerRequest` | 0 | 单个 HTTP 请求记录的方法调用总数，超出次数计入请求的省略数。 |
| `maxSnapshotValuesPerCall` | 1000 | 单次方法调用的入参、返回值或异常及 Koa 响应正文合计的快照值数。 |

达到快照上限时，后续值显示截断标记，调用状态和耗时仍会记录。重复、嵌套和并发调用各自拥有快照额度。缺失或停用的字典项按该项默认值运行。已启用的值非法或系统服务读取失败时，启动接口返回错误，管理员可修正字典或恢复系统服务后重试。

每个服务实例同时运行一个探针。会话归启动账号所有，最长 30 分钟，同时跟踪最多 12 个匹配请求。项目内切换接口共用同一进程和会话。每个已采集请求的调用持续记录到请求结束，子进程按顺序批量发送事件，传输繁忙时延后发送。服务关闭或父进程断开时结束目标进程。

浏览器连接持续期间，服务会保留该连接尚未读完的事件，恢复读取后按序补送。浏览器断线重连时可按序号回放最近 12,000 条事件、约 8 MiB，两项上限取先到者。会话结束后可回放 5 分钟，新会话会替换上次记录。
