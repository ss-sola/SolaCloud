# 接口清单

以下接口均经过管理网关，使用 SolaCloud 登录会话与 `system:call-graph:debug` 权限。JSON 响应使用 SDK 的 `{ code, message, data }` 包装。[OpenAPI 文件](./openapi.json)包含路径、请求参数和响应字段。

| 方法 | 路径 | 输入与结果 |
| --- | --- | --- |
| POST | `/api/call-graph/scan` | 输入 `project`，返回框架 `framework`（`koa`、`nestjs`、`unknown`）、可选的项目内相对启动入口 `entry`、`routes` 和扫描提示 |
| POST | `/api/call-graph/graph` | 输入 `project, routeId`，返回 `roots, nodes, edges, warnings` |
| POST | `/api/call-graph/start` | 输入 `project` 启动项目探针，返回 `sessionId`。旧客户端可附带 `routeId`，仅跟踪该接口。监听就绪通过事件通知 |
| POST | `/api/call-graph/stop` | 输入 `sessionId`，目标退出后返回 `ok` |
| GET | `/api/call-graph/events` | 查询参数 `sessionId` 和可选的 `after`，按 NDJSON 格式返回回放和实时事件 |

事件均带单调递增的 `seq`。活动会话在写完当前回放记录后发送首个空行，接下来是实时事件，后续空行用于保活。HTTP 404 表示会话失效或归属其他账号，409 表示分析或进程冲突，410 表示游标早于回放窗口。

| type | 字段 |
| --- | --- |
| status | state 为 starting、listening、stopped 或 error，可带 port 与 message |
| warning | message 描述采集时的提示，例如某个编译文件的源码映射不可用 |
| request | requestId、routeId（扫描清单的接口 ID）、method、path（实际请求路径）、startedAt（Unix 毫秒） |
| enter | requestId、routeId、callId、parentId、node、args（形参名与值的快照） |
| leave | requestId、callId、state（ok 或 error）、result、durationMs |
| end | requestId、status（HTTP 状态）、durationMs、dropped（本请求省略的调用次数） |

静态图的 `nodes[]` 和进入事件的 `node` 共享方法描述，包含 `id`、`name`、`file`、`line` 和两个可选布尔字段。`anonymous` 为真表示匿名函数。`computationOnly` 为真表示本次分析将该方法识别为纯同步计算。旧版本结果可能缺少标记，开启计算方法过滤时仍会保留这些节点。
