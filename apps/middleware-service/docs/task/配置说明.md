# 配置说明

- `QueueRedisUrl`：BullMQ Redis URL，必填；账号、密码和 DB 统一写入 URL，例如 `redis://user:pass@localhost:6379/0`。
- `QueuePrefix`：Redis key 前缀，默认 `middleware`，共用 Redis 时通过 prefix 做业务隔离。
- `QueueDefaultConcurrency`：worker 默认并发数，默认 2。
- `QueueDefaultAttempts`：默认重试次数，默认 3。
- `QueueDefaultBackoffMs`：默认退避毫秒数，默认 5000。
- `QueueCleanupCron`：上传临时文件清理 cron，默认 `15 */1 * * *`。
- `BullBoardEnabled`：是否启用 bull-board，默认关闭；启用后会展示所有任务类型队列。
- `BullBoardRoute`：bull-board 挂载路径，默认 `/admin/queues`。
