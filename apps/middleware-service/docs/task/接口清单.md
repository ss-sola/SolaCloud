# 接口清单

## POST /task/create

创建一次性任务。服务按 `name` 路由到对应任务类型队列。

Body：

- `name`：任务名称，当前支持 `upload-cleanup`。
- `data`：可选任务数据。
- `delayMs`：可选延迟执行毫秒数。

返回：

- `id`：BullMQ job id。
- `name`：任务名称。
- `queueName`：任务所在队列名称。
- `state`：任务状态。

## GET /task/detail

Query 参数：

- `id`：BullMQ job id。
- `name`：可选任务名称；传入后只查询该任务类型对应队列，不传时会遍历当前已注册队列。

## DELETE /task/remove

Query 参数：

- `id`：BullMQ job id。
- `name`：可选任务名称；传入后只删除该任务类型对应队列中的任务，不传时会遍历当前已注册队列。

返回：

- `id`：BullMQ job id。
- `removed`：是否删除成功。
- `queueName`：删除成功时返回任务所在队列名称。

## GET /task/queue

返回当前任务队列清单。

返回：

- `queueName`：默认队列名称，兼容旧字段。
- `queues`：队列列表，包含 `taskName` 与 `queueName`。
