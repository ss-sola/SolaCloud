# 模块总览

任务模块基于 BullMQ 实现异步任务与定时任务。首版内置上传临时文件清理任务，同时提供通用任务入队、状态查询、删除和队列清单接口。

BullMQ 依赖 Redis。服务只使用 `QueueRedisUrl` 配置 Redis 连接；账号、密码和 DB 统一写入 URL。共用 Redis 时通过 `QueuePrefix` 做业务 key 隔离。

任务模块按任务类型拆分 Queue 和 Worker。当前内置任务 `upload-cleanup` 使用独立队列 `middleware-task-upload-cleanup` 和独立 Worker，后续新增任务类型时应新增对应队列与 Worker。
