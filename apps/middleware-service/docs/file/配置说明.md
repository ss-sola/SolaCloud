# 配置说明

- `UploadRootDir`：正式文件上传根目录，默认 `public/uploads`。
- `UploadMaxSizeBytes`：单文件最大字节数，也是分片上传允许的总文件大小上限，默认 20MB。
- `UploadChunkTempRootDir`：分片临时目录根路径，默认 `var/uploads/chunks`，必须放在非公开目录下。
- `UploadPublicBaseUrl`：正式文件公开访问前缀，默认 `/public/uploads`；配置为相对路径时，接口返回会结合当前请求 origin 组装成完整路径。
- `UploadTempTtlMs`：正式临时文件和未完成上传会话的保留时长，默认 24 小时。
- `FileUploadRedisPrefix`：上传中间态 Redis key 前缀，默认 `file:upload`。

当前模块不再提供普通直传上传协议；上传入口统一为分片上传的 `check / upload / merge` 三接口。

## Redis 中间态

上传过程中的中间态通过 Redis 保存，当前默认 key 结构为：

- `${FileUploadRedisPrefix}:meta:${fileId}`：上传会话元信息。
- `${FileUploadRedisPrefix}:chunks:${fileId}`：已成功落盘的分片索引集合。
- `${FileUploadRedisPrefix}:lock:${fileId}`：合并过程互斥锁。

所有 key 的 TTL 统一复用 `UploadTempTtlMs`。

## 表结构说明

`middleware_file_upload_session` 继续保留，用于审计、回退恢复和过期清理。典型字段包括：

- `upload_id`
- `original_name`
- `mime_type`
- `total_size`
- `chunk_size`
- `chunk_count`
- `uploaded_bytes`
- `uploaded_chunk_count`
- `chunk_dir_path`
- `file_fingerprint`（当前用于保存 `fileId`）
- `scene`
- `business_type`
- `is_temporary`
- `status`
- `file_id`
- `error_message`
- `expires_at`

正式文件元数据仍保存在 `middleware_file_item`。

如果当前环境没有开启 TypeORM 自动同步，需要按实体定义补充建表和索引。
