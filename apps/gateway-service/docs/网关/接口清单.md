# 接口清单

| 接口 | 作用 |
| --- | --- |
| `GET /health/live` | 进程探针 |
| `GET /health/ready` | 配置正常且静态模式可接流量，或注册模式具有最近的有效快照 |
| `/api/system/...` | 前端使用的账号认证、系统管理和监控 API |
| `GET /api/system/trace-logs` | 按 traceId 查询网关和服务实例日志，由 system-service 校验会话和查询权限 |
| `GET /api/system/trace-logs/detail` | 按 traceId 和 entryId 加载单条原文，由 system-service 校验当前会话和查询权限 |
| `/api/file/...` | 上传检查、分片、合并、列表、详情、文件树和删除 |
| `/api/knowledge/...`、`/api/chat/...` | 知识库和聊天 API，`POST /api/chat/send` 透传 SSE |
| `OPTIONS /api/...` | 允许的前端来源预检已公开的业务方法和路径时返回 204 |

`GET /api/system/dictionaries/runtime` 只开放前端使用的 `common` 命名空间。服务配置字典和 `POST /api/knowledge/ingest` 走私网服务入口。

业务响应沿用上游状态、响应头和正文。网关以 400 表示路径格式错误，403 表示浏览器来源未获准，404 表示未开放的方法或路径，413 表示请求体超限，502 表示转发失败，503 表示缺少上游或实例快照过期，504 表示等待上游超时。
