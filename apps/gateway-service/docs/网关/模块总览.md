# 模块总览

gateway-service 是 SolaCloud 管理前端直接访问的 HTTP API 入口。路由服务按方法和路径匹配公开端点，实例服务解析静态地址或注册中心实例，转发服务在浏览器和业务服务之间传输原始 HTTP 请求与响应。

本地执行 `pnpm start:gateway`，浏览器直接访问 3100 上的 `/api`。生产在前端构建时指定 HTTPS 网关地址，并在网关配置允许的前端来源。控制面、Bull Board、任务、附件回调和服务间 RPC 通过各自的私网入口访问。

业务服务继续维护共享登录态与权限。文件上传和查询详情要求登录，管理列表和删除需要 `system:attachment:manage`。已登录账号可以使用现有共享知识库及其自己的聊天会话。文件下载和预览位于独立文件 origin。
