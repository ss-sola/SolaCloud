# 集中日志查询接口

`GET /api/system/trace-logs?traceId=<traceId>` 通过 SolaCloud 网关访问。列表和原文都要求当前有效的后台会话及 `system:trace-log:query` 权限。参数 `traceId` 接受 32 位非全零十六进制字符，查询时统一转成小写。

成功时返回标准响应，`data` 包含 `list` 和 `truncated`。列表按日志写入时间升序排列，未命中时返回空数组。超出 500 条时，优先保留网关与接单结果，再补较早的普通日志，`truncated` 为 `true`。响应设置 `Cache-Control: no-store`。

| 日志字段 | 说明 |
| --- | --- |
| `entryId` | 用于按需查询该条原文的不透明标识 |
| `timestampNs` | Unix 纳秒时间戳的字符串表示 |
| `service` | 发出该条日志的服务 |
| `instance` | 发出该条日志的实例标识 |
| `instanceAddress` | 实例地址，如 `127.0.0.1:3201`。无地址标签且无法从实例标识解析时为 `null` |
| `level` | 日志级别，缺失时为 `null` |
| `message` | 前 1200 个 Unicode 码位的日志预览，可包含多行。HTTP 详情从预览中移除，保留 span 关联字段 |

### 按需查询原文

`GET /api/system/trace-logs/detail?traceId=<traceId>&entryId=<entryId>` 返回标准响应，`data.message` 为该条完整日志，可包含多行。请求完成日志的 JSON 原文可包含已脱敏的 httpDetails。每组详情含 state 以及可选的 value。原文最多 256 KiB，响应设置 `Cache-Control: no-store`。

缺少会话或查询权限时返回 403，已有会话失效时返回 401。参数无效返回 400。原文已不可用时返回 404，无法唯一定位时返回 409，超过原文上限时返回 413。Loki 尚未配置或查询失败返回 503。
