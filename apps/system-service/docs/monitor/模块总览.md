# monitor 模块总览

## 模块职责

监控模块负责提供当前 `system-service` 实例的在线用户会话与服务运行指标查询能力，为管理台“系统监控”菜单提供数据来源。

## 当前定位

- 作为 `system-service` 的运行观察入口
- 在线用户监控基于当前进程内存注册表，只代表当前实例观察到的 session
- 服务监控基于 Node 内置能力采集 CPU、内存、磁盘与服务器信息

## 核心入口

- 控制器：`apps/system-service/src/modules/monitor/controller/monitor.controller.ts`
- 在线用户服务：`apps/system-service/src/modules/monitor/service/online-user.service.ts`
- 服务指标服务：`apps/system-service/src/modules/monitor/service/service-monitor.service.ts`
- 表单：`apps/system-service/src/modules/monitor/form/online-user-query.form.ts`
- 类型：`apps/system-service/src/modules/monitor/monitor.types.ts`

## 对外能力

- 监控总览查询
- 当前实例在线用户分页查询
- 服务 CPU、内存、磁盘空间、服务器信息查询
