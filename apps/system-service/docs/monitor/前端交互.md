# 前端交互

## 访问入口

- 左侧菜单分组：系统监控

## 在线用户监控

页面职责：

- 展示当前实例在线用户列表
- 支持按账号、IP、User-Agent 关键词过滤
- 展示登录时间、最近活跃时间、过期时间和头像
- 支持分页与手动刷新
- 支持在操作列踢出在线用户

对接接口：

- `GET /api/system/monitors/overview`
- `GET /api/system/monitors/online-users`
- `DELETE /api/system/monitors/online-users`

页面说明：

- 顶栏“刷新在线用户”会重新拉取总览和列表
- 账号列展示头像，未配置头像时使用显示名首字作为 fallback
- User-Agent 使用自动换行展示，避免撑开页面
- 点击“踢人下线”会先弹出确认框，确认后调用接口并局部刷新当前列表

## 服务监控

页面职责：

- 展示 CPU 指标
- 展示内存指标
- 展示磁盘空间指标
- 展示服务器信息

对接接口：

- `GET /api/system/monitors/overview`
- `GET /api/system/monitors/service`

页面说明：

- 顶栏“刷新服务监控”会重新拉取总览和服务指标
- 磁盘采集可用时展示总量、已用、空闲和使用率
- 磁盘采集失败时展示路径、不可用状态和错误说明
