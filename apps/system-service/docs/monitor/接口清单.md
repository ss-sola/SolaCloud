# 接口清单

## 路由前缀

- 全局前缀：`/api`
- 模块前缀：`/system/monitors`

## 接口列表

### `GET /api/system/monitors/overview`

获取监控模块总览。

权限：具备以下任一权限即可访问：

- `system:monitor:online-user:query`
- `system:monitor:service:query`

返回字段：

- `service`：服务名
- `onlineUserCount`：当前实例在线用户数
- `capabilities`：监控能力标识

### `GET /api/system/monitors/online-users`

分页查询当前实例在线用户。

权限：`system:monitor:online-user:query`

查询参数：

- `pageNum`：页码
- `pageSize`：每页条数
- `keyword`：可选，按账号名、展示名、IP、User-Agent 模糊过滤

返回数组字段统一为 `list`，单条记录包含：

- `sessionId`
- `accountId`
- `accountName`
- `displayName`
- `avatarUrl`
- `ip`
- `userAgent`
- `loginAt`
- `lastActiveAt`
- `expiresAt`

### `DELETE /api/system/monitors/online-users`

踢出指定在线用户并销毁目标 session。

权限：`system:monitor:online-user:kick`

请求体：

```json
{
  "sessionId": "target-session-id"
}
```

字段说明：

- `sessionId`：必填，在线用户列表返回的会话标识

返回字段：

- `sessionId`：被踢出的会话标识
- `kicked`：固定为 `true`

错误场景：

- 目标会话不存在或已过期
- 不能踢出当前登录会话
- 当前会话存储未配置 Redis session，不支持主动销毁其他会话
- Redis session 销毁失败

### `GET /api/system/monitors/service`

查询当前服务运行指标。

权限：`system:monitor:service:query`

返回字段：

- `collectedAt`：采集时间
- `cpu`：CPU 型号、核心数、负载、运行时长
- `memory`：系统内存与当前 Node 进程内存
- `disk`：当前服务工作目录所在磁盘空间；采集失败时 `available=false` 并返回 `errorMessage`
- `server`：主机名、平台、架构、系统版本、Node 版本、PID
