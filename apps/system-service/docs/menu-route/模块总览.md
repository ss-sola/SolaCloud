# menu-route 模块总览

## 模块职责

菜单路由模块负责维护 `system-service` 输出给 `NestCloudWeb` 的运行时菜单树。前端通过 `routeName` 查找页面，`routeRoot` 标识所属产品域。

## 当前定位

- 作为 `system-service` 的核心资源层模块之一，负责系统管理与 AI 助手的菜单和分组节点的统一维护。
- `code` 是服务内唯一且稳定的菜单标识，只在创建时填写，更新时保持不变。
- `component` 决定页面绑定键；`icon` 只保存 SVG 名称，前端可解析到静态资源或回退为纯文本展示。
- `meta.group = true` 表示分组节点；`meta.routeRoot` 表示一级域归属。
- 默认菜单数据见 `sql/init_data.sql` 中的 `sys_menu_route` 和 `sys_menu_route_permission`。
- 废弃的 `runtime-permission-management` 不再出现在默认菜单和运行时导航中。

## 核心入口

- 控制器：`apps/system-service/src/modules/menu-route/controller/menu-route.controller.ts`
- 服务：`apps/system-service/src/modules/menu-route/service/menu-route.service.ts`
- 实体：`apps/system-service/src/modules/menu-route/entity/menu-route.entity.ts`
- 工具：`apps/system-service/src/modules/menu-route/menu-route.util.ts`
- 表单：`apps/system-service/src/modules/menu-route/form/*.ts`
- 旧版菜单结构的一次性同步脚本：`apps/system-service/scripts/sync-menu-route-data.cjs`
- 初始化 SQL：`sql/init_data.sql`

## 数据模型

- 表名：`sys_menu_route`
- 存储：PostgreSQL
- 关键字段：
  - `code`：菜单编码，服务内唯一，更新接口不允许修改
  - `name`：菜单名称
  - `path`：一级域内路由路径
  - `parentId`：父菜单 ID
  - `component`：前端页面组件标识
  - `redirect`：前端重定向路径
  - `icon`：菜单图标名称，对应前端静态资源或文本回退
  - `sort`：同级排序值
  - `isEnabled`：是否启用
  - `isHidden`：是否隐藏
  - `permissionCodes`：访问该菜单所需权限码列表
  - `meta`：前端路由扩展元数据，当前主要用于 `group` 与 `routeRoot`

## 对外能力

- 总览查询
- 列表查询
- 树查询
- 单项查询
- 新增、更新、删除
- 权限码绑定与校验
- 批量启停
- 排序调整
- 运行时菜单树输出（含 `component`、`icon`、`path`、`meta.routeRoot`）
