# 前端交互

## 访问入口

- 页面模块：角色管理

## 页面职责

角色管理页负责把角色中心、权限绑定和运行态预览接口组织成可直接操作的后台管理界面，覆盖以下能力：

- 按关键词、启停状态筛选角色
- 新增 / 编辑角色
- 通过“可筛选表格 + 勾选”维护权限码绑定
- 预览角色运行态菜单树

## 对接接口

- `GET /api/system/roles/overview`
- `GET /api/system/roles`
- `GET /api/system/roles/item?id=...`
- `GET /api/system/roles/runtime?roleCode=...`
- `POST /api/system/roles`
- `PUT /api/system/roles/item?id=...`
- `DELETE /api/system/roles/item?id=...`
- `GET /api/system/permissions`

## 页面交互说明

- 页面初始化时同时拉取角色列表与权限资源
- 角色列表名称列只展示名称，不展示描述
- 角色列表只展示权限码绑定结果，不再展示菜单 ID、用户 ID 绑定列
- 角色列表支持点击表头排序，未排序字段显示 `↕`，当前排序字段显示 `↑` 或 `↓`
- 分页区展示总数、当前页、总页数、页码按钮和每页条数选择，切换分页条件后局部刷新列表
- 新增入口保留在页面筛选工具栏内，顶栏不再重复展示“新增角色 / 刷新角色”按钮
- 新增与编辑共用同一个 modal
- 权限选择区使用表格展示，字段包含：选择、权限码、名称、分组、状态、说明
- 权限选择区支持 `keyword`、`groupKey`、`isEnabled` 三个筛选维度
- “全选当前筛选”“清空当前筛选”只作用于当前筛选结果
- 编辑角色时会根据当前绑定关系自动回显已选权限码
- 保存时前端只提交 `permissionCodes`
- 运行态预览区支持按角色编码刷新，可查看当前角色可用菜单树
- 删除前使用浏览器确认框二次确认
