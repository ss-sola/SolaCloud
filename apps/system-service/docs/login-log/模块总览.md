# login-log 模块总览

## 模块职责

登录日志模块负责记录后台账号安全事件，并提供按账号、事件类型、结果的查询入口。

## 当前定位

- 作为第一阶段安全事件可观测能力的落地点
- 记录登录成功、登录失败、锁定、登出、密码重置等事件
- 为账号页和后续审计增强提供安全事件数据基础

## 核心入口

- 控制器：`apps/system-service/src/modules/account/controller/login-log.controller.ts`
- 服务：`apps/system-service/src/modules/account/service/login-log.service.ts`
- 实体：`apps/system-service/src/modules/account/entity/login-log.entity.ts`
- 事件写入方：`apps/system-service/src/modules/account/service/account.service.ts`

## 对外能力

- 总览查询
- 登录日志列表查询
- 按账号名过滤
- 按事件类型过滤
- 按成功 / 失败过滤
