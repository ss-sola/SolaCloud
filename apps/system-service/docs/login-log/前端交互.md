# 前端交互

## 访问入口

- 页面模块：登录日志

## 页面职责

登录日志页负责查询后台账号安全事件，覆盖以下能力：

- 查看日志总览
- 按账号名、事件类型、结果过滤
- 查看消息、IP、User-Agent、创建时间
- 快速刷新当前日志列表

## 对接接口

- `GET /api/system/login-logs/overview`
- `GET /api/system/login-logs`

## 页面交互说明

- 顶栏提供“刷新登录日志”按钮
- 筛选表单支持账号名、事件类型、成功结果、返回条数
- 成功结果筛选、事件类型展示和成功/失败展示通过 `common` 命名空间的字典运行态读取，分别使用 `success-state.`、`login-log.event-type.` key 前缀；未命中字典时展示原始事件类型
- 日志列表支持按 ID、创建时间排序，排序切换后局部刷新列表
- 重置按钮会恢复默认返回条数 `100`
- 列表为空时展示空状态，不做整页刷新
