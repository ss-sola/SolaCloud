# 接口清单

## `GET /api/system/login-logs/overview`

返回登录日志模块总览，包括服务名、日志总数与能力列表。

## `GET /api/system/login-logs`

查询登录日志列表。

查询参数：

- `accountName`：按账号名过滤
- `eventType`：按事件类型过滤
- `success`：按是否成功过滤
- `limit`：限制返回条数，默认 `100`

返回字段：

- `id`
- `accountId`
- `accountName`
- `eventType`
- `success`
- `message`
- `ip`
- `userAgent`
- `createdAt`
- `updatedAt`
