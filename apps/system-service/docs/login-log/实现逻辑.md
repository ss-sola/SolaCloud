# 实现逻辑

## 1. 事件写入来源

当前登录日志主要由 `AccountService` 写入，覆盖以下场景：

- 登录成功
- 登录失败
- 登录失败达到阈值后的锁定
- 登出
- 密码重置

## 2. 查询逻辑

`LoginLogService.listItems()` 直接按条件拼装 `where`，支持：

- `accountName`
- `eventType`
- `success`
- `limit`

当前实现返回最近记录优先，按 `id DESC` 排序。

## 3. 当前边界

当前登录日志能力仍是第一阶段轻量实现：

- 已支持基础筛选与列表展示
- 还没有分页、时间范围筛选与详情页
- 审计上下文字段提取、脱敏白名单和统一拦截器仍属于第二阶段工作
