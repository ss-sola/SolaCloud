# auth 模块总览

## 模块职责

登录态模块负责管理前后台统一账号主体的登录、登出、会话刷新与当前账号输出，对外提供统一的 session 主体结构。

## 当前定位

- 作为 `system-service` 身份访问底座的会话入口
- 前台用户和后台管理用户都通过 `account` 建立登录态
- 复用 `NestCloud-Sdk` 的 `createRedisSession(...)` 中间件
- 统一输出 `accountId`、`accountName`、`displayName`、`statusVersion`、`loginAt`
- 提供账号页顶部登录、登出、当前会话刷新能力

## 核心入口

- 控制器：`apps/system-service/src/modules/account/controller/auth.controller.ts`
- 服务：`apps/system-service/src/modules/account/service/account.service.ts`
- 启动接入：`apps/system-service/src/main.ts`
- 配置键：`apps/system-service/src/config-keys.ts`
- 配置校验：`apps/system-service/src/validate.config.ts`

## 会话配置

当前通过 `createRedisSession(...)` 接入 session，支持以下配置键：

- `SessionRedisUrl`
- `SessionSecret`
- `SessionCookieName`
- `SessionTtlMs`
- `SessionKeyPrefix`
- `SessionSameSite`
- `SessionSecure`
