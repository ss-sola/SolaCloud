# 前端交互

## 访问入口

- 管理台入口由 `web/NestCloudWeb` 提供
- 启动时先调用 `GET /api/system/auth/current` 校验当前 session，未登录时不加载侧边栏和页面数据
- 登录成功后由后端写入 session cookie，前端隐藏登录页，按当前 hash 局部刷新侧边栏和页面
- 跨域调试时前端请求需要携带 credentials，后端 CORS 会返回凭证响应头
- 当前登录人信息统一展示在全局顶部 header，不再由账号页维护当前会话卡片

## 对接接口

- `POST /api/system/auth/login`
- `POST /api/system/auth/logout`
- `POST /api/system/auth/refresh`
- `GET /api/system/auth/current`

## 页面交互说明

- 登录页只包含账号名、密码和登录提交能力
- 启动校验或登录成功后缓存当前账号，并在顶部 header 展示名称、头像与登出入口
- 未配置头像时，顶部 header 使用显示名或账号名首字作为 fallback
- 顶部 header“登出”调用登出接口，成功后回到登录页并隐藏管理台内容
- 登录成功后管理台刷新运行态菜单树与当前页面
