# 接口清单

## `POST /api/system/auth/login`

账号登录。

请求体字段：

- `accountName`
- `password`

返回统一 session 主体：

- `accountId`
- `accountName`
- `displayName`
- `avatarUrl`
- `statusVersion`
- `loginAt`

## `POST /api/system/auth/logout`

当前账号登出，并销毁当前 session。

## `POST /api/system/auth/refresh`

刷新当前 session 的账号主体信息。当前实现会保留原始 `loginAt`，避免刷新后把登录时间覆盖成刷新时间。

无有效会话时返回 HTTP 401。

## `GET /api/system/auth/current`

读取当前 session 对应的账号基础信息，返回：

- `accountId`
- `accountName`
- `displayName`
- `avatarUrl`

会话缺失、版本过期或账号被停用或删除时返回 HTTP 401。
