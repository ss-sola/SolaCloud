# notification 模块总览

## 模块职责

notification 模块负责沉淀后台公告与站内信能力，覆盖公告发布、生效期控制、站内信发送、未读统计和运行态预览。

## 当前定位

- 作为第三阶段通用管理底座中的通知能力落地点
- 管理 `sys_announcement` 与 `sys_station_message` 两张表
- 提供公告管理、站内信管理和运行态预览页面

## 核心入口

- 公告控制器：`apps/system-service/src/modules/notification/controller/announcement.controller.ts`
- 站内信控制器：`apps/system-service/src/modules/notification/controller/station-message.controller.ts`
- 服务：`apps/system-service/src/modules/notification/service/notification.service.ts`
- 实体：`apps/system-service/src/modules/notification/entity/*.ts`
- 表单：`apps/system-service/src/modules/notification/form/*.ts`
- 常量：`apps/system-service/src/modules/notification/notification.constants.ts`

## 数据模型

### 公告 `sys_announcement`

- `title`：公告标题
- `content`：公告正文
- `isPublished`：是否发布
- `effectiveFrom` / `effectiveTo`：生效时间窗口
- `publishedAt`：首次发布时间
- `revokedAt`：撤回时间
- `publisherAccountId`：发布人账号 ID

### 站内信 `sys_station_message`

- `title`：消息标题
- `content`：消息正文
- `receiverAccountId`：接收账号 ID
- `senderAccountId`：发送人账号 ID
- `isRead`：是否已读
- `readAt`：已读时间

## 对外能力

- 公告总览、列表、单项查询
- 公告新增、编辑、删除
- 公告运行态查询
- 站内信列表查询
- 按账号发送站内信
- 广播发送站内信
- 未读数量查询
- 单条已读、全部已读
- 指定账号运行态站内信预览
