# 接口清单

## 公告管理接口

### `GET /api/system/announcements/overview`

返回通知模块总览，包含服务名、公告总数、站内信总数与能力列表。

### `GET /api/system/announcements`

查询公告列表。

查询参数：

- `keyword`：按标题或内容关键字筛选
- `isPublished`：按发布状态筛选

### `GET /api/system/announcements/item?id=...`

查询单条公告详情。

### `GET /api/system/announcements/runtime`

返回当前运行中的公告列表，只包含已发布、未撤回且处于生效时间窗口内的公告。

### `POST /api/system/announcements`

新增公告。

请求体字段：

- `title`
- `content`
- `isPublished`
- `effectiveFrom`
- `effectiveTo`

### `PUT /api/system/announcements/item?id=...`

更新公告。

### `DELETE /api/system/announcements/item?id=...`

删除公告。

## 站内信接口

### `GET /api/system/station-messages`

查询站内信列表。

查询参数：

- `receiverAccountId`
- `isRead`

### `GET /api/system/station-messages/runtime/current`

查询当前登录账号的运行态站内信列表。

查询参数：

- `isRead`：可选；按已读状态筛选

### `GET /api/system/station-messages/unread-count`

查询当前登录账号的未读站内信数量。

### `POST /api/system/station-messages/send`

发送站内信。

请求体字段：

- `title`
- `content`
- `isBroadcast`：`true` 时按全部启用账号广播
- `receiverAccountIds`：定向发送时必填

### `PUT /api/system/station-messages/read?id=...`

将当前登录账号名下的单条站内信标记为已读。服务端会校验消息归属，不能按 ID 标记其他账号消息。

### `PUT /api/system/station-messages/read-all`

将当前登录账号的未读站内信全部标记为已读。
