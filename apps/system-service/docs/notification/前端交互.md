# 前端交互

## 访问入口

- 页面模块：通知公告

## 页面职责

通知公告页负责把公告管理接口、站内信接口和运行态预览接口组织成一个管理闭环，覆盖以下能力：

- 查看公告与站内信总览
- 按关键字、发布状态筛选公告
- 新增 / 编辑 / 删除公告
- 查看当前运行中的公告
- 按接收账号与已读状态筛选站内信
- 发送定向站内信
- 发送广播站内信
- 查询指定账号未读数
- 将指定账号站内信全部标记为已读
- 预览指定账号运行态站内信列表

- `GET /api/system/announcements`

- `GET /api/system/announcements/runtime`

- `DELETE /api/system/announcements/item?id=...`

- `GET /api/system/station-messages/runtime/current`
- `GET /api/system/station-messages/unread-count`
- `POST /api/system/station-messages/send`
- `PUT /api/system/station-messages/read?id=...`
- `PUT /api/system/station-messages/read-all?receiverAccountId=...`

## 页面交互说明

- 顶栏提供刷新数据、新增公告、发送站内信三个快捷入口
- 公告区展示筛选表单、总览卡片和公告表格，公告表格支持按 ID、生效时间、发布时间排序
- 站内信区支持按接收账号查看消息列表，并提供未读数刷新和全部已读操作，站内信表格支持按 ID、发送时间排序
- 发送站内信 modal 支持两种模式：
  - 按账号发送：在多选框中挑选启用账号
  - 广播发送：直接向全部启用账号发送
- 发布状态、读取状态和发送方式选项通过 `common` 命名空间的字典运行态读取，分别使用 `notification.publish-state.`、`notification.read-state.`、`notification.send-mode.` key 前缀；保存和筛选时仍使用原始布尔值或 `account / broadcast` 模式值
- 页面底部单独展示运行态预览卡片，用于核对当前生效公告和指定账号的消息运行态
