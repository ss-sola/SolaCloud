# dictionary 模块总览

## 模块职责

字典模块负责统一维护命名空间、字典与字典项，向后台管理与其他服务提供标准化的查询、写入、删除、批量导入和运行态读取能力。

## 当前定位

- 作为 `system-service` 的核心资源层模块之一。
- 命名空间只作为中性的管理维度，不承载具体业务分组语义。
- 字典承载同一命名空间下的选项组语义，例如 `system-param.value-type`、`notification.read-state`。
- 字典项 key 只表示字典内局部键，不再通过前缀表达分组。
- 提供后台管理可直接使用的命名空间、字典和字典项接口。
- 新库从 `sql/init_data.sql` 取得初始字典。已有库使用对应功能的增量补丁。
- 运行态查询只暴露启用中的命名空间、字典与字典项。

## 核心入口

- 控制器：`apps/system-service/src/modules/dictionary/controller/dictionary.controller.ts`
- 运行态控制器：`apps/system-service/src/modules/dictionary/controller/dictionary-runtime.controller.ts`
- 服务：`apps/system-service/src/modules/dictionary/service/dictionary.service.ts`
- 实体：
  - `apps/system-service/src/modules/dictionary/entity/dictionary-namespace.entity.ts`
  - `apps/system-service/src/modules/dictionary/entity/dictionary-aggregate.entity.ts`
  - `apps/system-service/src/modules/dictionary/entity/dictionary-item.entity.ts`
- 常量：`apps/system-service/src/modules/dictionary/dictionary.constants.ts`
- 表单：`apps/system-service/src/modules/dictionary/form/*.ts`

## 数据模型

- 命名空间表：`sys_dict_namespace`
- 字典表：`sys_dict_aggregate`
- 字典项表：`sys_dict_item`
- 存储：PostgreSQL
- 关键字段：
  - `namespace`：命名空间。
  - `aggregate_key`：字典编码，同一 namespace 内唯一。
  - `dict_key`：字典项局部键，同一 `namespace + aggregate_key` 内唯一。
  - `value`：字典值，支持 JSON。
  - `label`：显示名。
  - `description`：说明。
  - `isEnabled`：命名空间、字典和字典项均支持启停。

## 模块约束

- 字典数据属于业务基础数据，不通过配置中心注入。
- 管理员可在字典管理中修改已有项或导入新项。
- 控制器只负责参数接收与响应封装。
- 路由常量统一收敛在 `DICTIONARY_CONTROLLER_ROUTE`。
- 字典项 key 不允许继续使用业务前缀表达分组，分组必须落在 `aggregateKey`。
- 运行态接口必须携带 `namespace + aggregateKey`。

## 对外能力

- 总览查询。
- 命名空间列表 / 单项查询 / upsert / 删除空命名空间。
- 字典列表 / 单项查询 / upsert / 删除空字典。
- 字典内字典项列表查询。
- 按 keys 批量获取字典内字典值。
- 字典项单项查询 / 新增 / 更新 / 删除。
- 批量导入与导入摘要返回。
- 运行态只读查询。
