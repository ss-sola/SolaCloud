# 前端交互

## 访问入口

- 页面模块：命名空间管理、字典管理

## 页面职责

命名空间管理页负责维护中性的 namespace 元信息；字典管理页主页面负责按 namespace 以表格维护字典，字典编辑弹窗负责维护该字典下的字典项。两类页面共同覆盖以下能力：

- 查询命名空间列表与元信息。
- 新增 / 编辑 / 删除空命名空间。
- 按命名空间分页查询字典表格。
- 新增 / 编辑 / 删除空字典。
- 在编辑字典弹窗内按 `namespace + aggregateKey` 查看字典项列表。
- 在编辑字典弹窗内新增 / 编辑 / 删除字典项。
- 在编辑字典弹窗内批量导入显式字典结构的字典项。
- 为其他页面提供运行态字典下拉选项和展示文案。

## 对接接口

- `GET /api/system/dictionaries/overview`
- `GET /api/system/dictionaries/namespaces`
- `GET /api/system/dictionaries/namespace?namespace=...`
- `PUT /api/system/dictionaries/namespace?namespace=...`
- `DELETE /api/system/dictionaries/namespace?namespace=...`
- `GET /api/system/dictionaries/aggregates?namespace=...`
- `GET /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`
- `PUT /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`
- `DELETE /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`
- `GET /api/system/dictionaries/items?namespace=...&aggregateKey=...&keys=...`
- `GET /api/system/dictionaries/runtime?namespace=...&aggregateKey=...&keys=...`
- `GET /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`
- `PUT /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`
- `DELETE /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`
- `POST /api/system/dictionaries/import`

## 页面交互说明

### 1. 命名空间管理

- 页面初始化时拉取总览和命名空间列表。
- 查询区支持按 namespace、label、description 关键词和启停状态过滤。
- 列表展示 namespace、label、description、启停状态、字典数量、字典项数量和更新时间。
- 新增与编辑共用同一个 modal，可维护 `label`、`description` 与 `isEnabled`。
- 删除命名空间前使用浏览器确认框二次确认；非空命名空间删除失败时直接展示接口错误。

### 2. 字典管理

- 字典管理页先选择 namespace，再以单表格展示该 namespace 下的字典。
- 字典表格展示中文名称、启停状态、字典项数量、描述、更新时间和操作入口。
- 主页面不直接展示字典项明细，点击字典行只用于当前字典高亮。
- 新增字典只维护字典元信息；编辑字典会打开弹窗并展示字典元信息和字典项列表。
- 字典承载业务分组语义，例如 `enabled-state`、`system-param.value-type`、`notification.read-state`。
- 字典删除失败时直接展示接口错误，提示先清空字典下字典项。

### 3. 编辑弹窗内字典项列表

- 编辑字典弹窗内只展示当前 `namespace + aggregateKey` 下的数据。
- 字典项列表支持按 Key、更新时间等字段排序，不展示分页控件。
- 字典项新增与编辑共用同一个 modal，从编辑字典弹窗内触发。
- 字典项 key 是字典内局部键，例如 `true`、`false`、`string`，不再填写 `enabled-state.true` 这类前缀 key。
- `value` 输入区支持普通字符串或 JSON 文本：可解析时按 JSON 提交，不可解析时按原始字符串提交。
- 字典项支持启停状态编辑。
- 新增、编辑、删除字典项成功后刷新弹窗内字典项列表，并刷新主页面字典表格中的数量和更新时间。

### 4. 批量导入

- 导入 modal 从编辑字典弹窗内触发，默认填充当前 namespace 和当前字典编码。
- 导入 modal 接收 `namespace + label + description + items(JSON Array)`。
- `items` 必须是 JSON 数组，每一项必须包含 `aggregateKey + key + value`。
- 导入成功提示会展示新增、更新、跳过数量。
- 提交成功后刷新弹窗内字典项列表，并刷新主页面字典表格中的数量和更新时间。

### 5. 运行态选项

- 其他页面通过 `GET /api/system/dictionaries/runtime` 读取启用字典项，作为下拉选项和展示文案来源。
- `hydrateDictionarySelect(...)` 必须传 `aggregateKey`，不再支持 `keyPrefix`。
- `getCommonDictionaryLabel(aggregateKey, value, fallback)` 用于从 `common` 命名空间读取指定字典下的展示文案。
- 字典加载失败或未命中时保留静态 HTML 选项、原始值或当前中文默认文案，不阻塞业务列表刷新。
