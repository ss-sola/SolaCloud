# 接口与导入规则

## 路由前缀

- 全局前缀：`/api`
- 模块前缀：`/system/dictionaries`

## 接口清单

- `GET /api/system/dictionaries/overview`：获取模块总览。
- `GET /api/system/dictionaries/namespaces`：获取所有命名空间摘要。
- `GET /api/system/dictionaries/namespace?namespace=...`：获取单个命名空间元信息。
- `PUT /api/system/dictionaries/namespace?namespace=...`：新增或更新命名空间元信息。
- `DELETE /api/system/dictionaries/namespace?namespace=...`：删除空命名空间。
- `GET /api/system/dictionaries/aggregates?namespace=...`：分页获取命名空间下的字典列表。
- `GET /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`：获取单个字典元信息。
- `PUT /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`：新增或更新字典元信息。
- `DELETE /api/system/dictionaries/aggregate?namespace=...&aggregateKey=...`：删除空字典。
- `GET /api/system/dictionaries/items?namespace=...&aggregateKey=...`：获取字典下的全部字典项列表。
- `GET /api/system/dictionaries/items?namespace=...&aggregateKey=...&keys=key1&keys=key2`：按一组 keys 批量获取字典项。
- `GET /api/system/dictionaries/runtime?namespace=...&aggregateKey=...&keys=key1&keys=key2`：运行态读取启用字典项，用于页面选项和展示文案。
- `GET /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`：获取单个字典项。
- `PUT /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`：新增或更新字典项。
- `DELETE /api/system/dictionaries/item?namespace=...&aggregateKey=...&key=...`：删除字典项。
- `POST /api/system/dictionaries/import`：批量导入命名空间字典项。

## 命名空间 upsert 请求结构

```json
{
  "label": "通用字典",
  "description": "system-service 默认命名空间",
  "isEnabled": true
}
```

## 字典 upsert 请求结构

```json
{
  "label": "系统参数值类型",
  "description": "系统参数 valueType 选项",
  "isEnabled": true
}
```

## 字典项 upsert 请求结构

```json
{
  "value": "string",
  "label": "字符串",
  "description": "文本类型参数",
  "isEnabled": true
}
```

## 导入请求结构

```json
{
  "namespace": "common",
  "label": "通用字典",
  "description": "system-service 默认通用字典",
  "items": [
    {
      "aggregateKey": "system-param.value-type",
      "key": "string",
      "value": "string",
      "label": "字符串",
      "description": "文本类型参数",
      "isEnabled": true
    }
  ]
}
```

## 查询与导入规则

- 所有资源标识统一通过 query 参数传递，不使用 RESTful 路径参数。
- `namespace` 必填，最大长度 64。
- `aggregateKey` 必填，最大长度 128。
- `keys` 可选，支持重复 query 参数或逗号分隔字符串。
- 单个 `key` 最大长度 128。
- 批量查询时仅返回命中的字典项，不因部分 key 不存在而报错。
- 运行态接口只返回启用命名空间、启用字典下的启用字典项；任一层不存在或停用时返回空列表，便于前端降级显示原始值。
- 删除命名空间仅允许删除空命名空间；若命名空间下仍有字典，接口返回业务异常，需要先删除字典。
- 删除字典仅允许删除空字典；若字典下仍有字典项，接口返回业务异常，需要先删除字典项。
- `items` 必填，且至少包含 1 个元素。
- 导入前会对 `aggregateKey` 和 `key` 做 trim、去空，并对同一次导入中的重复 `aggregateKey + key` 去重。
- 导入逻辑按 `namespace + aggregateKey + key` 进行幂等 upsert。
- 导入返回 `importedCount / createdCount / updatedCount / skippedCount`。
- 内置字典的安装使用 SQL 种子和增量补丁。探针配置的键与默认值见[实现逻辑](./实现逻辑.md)。
- 字典项 key 不再携带分组前缀，例如系统参数值类型使用 `aggregateKey = system-param.value-type`、`key = string`。
