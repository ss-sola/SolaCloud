# 前端交互

## 访问入口

- 页面模块：权限码管理

## 页面职责

权限码管理页负责把权限码中心的后端接口组织成可直接操作的后台管理界面，覆盖以下能力：

- 查看模块总览
- 按关键词、分组、启停状态筛选
- 新增 / 编辑权限码
- 删除权限码
- 查看分组与说明信息

## 对接接口

- `GET /api/system/permissions/overview`
- `GET /api/system/permissions`
- `GET /api/system/permissions/item?id=...`
- `POST /api/system/permissions`
- `PUT /api/system/permissions/item?id=...`
- `DELETE /api/system/permissions/item?id=...`

## 页面交互说明

- 页面初始化时拉取总览与权限码列表
- 新增与编辑共用同一个 modal
- 列表支持按 `groupKey` 和 `isEnabled` 过滤
- 权限分组展示和启停状态选项通过 `common` 命名空间的字典运行态读取，分别使用 `permission.group.`、`enabled-state.` key 前缀；分组筛选仍保留自由输入以兼容扩展分组
- 列表字段支持点击表头排序，未排序字段显示 `↕`，当前排序字段显示 `↑` 或 `↓`
- 分页区展示总数、当前页、总页数、页码按钮和每页条数选择，切换分页条件后局部刷新列表
- 新增入口保留在页面筛选工具栏内，顶栏不再重复展示“新增权限码 / 刷新权限”按钮
- 删除前使用浏览器确认框二次确认
- 保存或删除成功后自动刷新列表
