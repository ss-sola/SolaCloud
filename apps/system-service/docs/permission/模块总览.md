# permission 模块总览

## 模块职责

权限码模块负责统一维护系统权限资源，向菜单路由、角色中心和管理台页面提供稳定的权限码数据源。

## 当前定位

- 作为 `system-service` 的核心资源层模块之一
- 维护权限码基础信息、分组、说明与启停状态
- 为 `menu-route.permissionCodes` 提供合法性校验基础
- 为 `role` 模块提供权限绑定资源
- 为系统监控菜单提供在线用户监控查询与服务监控查询权限码

## 核心入口

- 控制器：`apps/system-service/src/modules/permission/controller/permission.controller.ts`
- 服务：`apps/system-service/src/modules/permission/service/permission.service.ts`
- 实体：`apps/system-service/src/modules/permission/entity/permission.entity.ts`
- 表单：`apps/system-service/src/modules/permission/form/*.ts`
- 常量：`apps/system-service/src/modules/permission/permission.constants.ts`

## 数据模型

- 表名：`sys_permission`
- 存储：PostgreSQL
- 关键字段：
  - `code`：权限码，服务内唯一
  - `name`：权限名称
  - `groupKey`：权限分组
  - `description`：权限说明
  - `isEnabled`：是否启用

## 对外能力

- 总览查询
- 列表查询
- 单项查询
- 新增、更新、删除
- 分组过滤
- 启停控制
- 菜单权限码校验
