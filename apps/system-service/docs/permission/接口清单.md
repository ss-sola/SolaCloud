# 接口清单

## 路由前缀

- 全局前缀：`/api`
- 模块前缀：`/system/permissions`

## 接口列表

- `GET /api/system/permissions/overview`：获取模块总览
- `GET /api/system/permissions`：按条件查询权限码列表
- `GET /api/system/permissions/item?id=...`：查询单个权限码
- `POST /api/system/permissions`：创建权限码
- `PUT /api/system/permissions/item?id=...`：更新权限码
- `DELETE /api/system/permissions/item?id=...`：删除权限码

## 创建/更新请求结构

```json
{
  "code": "system:dictionary:manage",
  "name": "字典管理",
  "groupKey": "resource",
  "description": "维护系统字典",
  "isEnabled": true
}
```

## 查询与写入规则

- 资源标识统一通过 query 参数传递，不使用路径参数
- `code`、`name` 必填，最大长度均为 64
- `groupKey` 可选，最大长度 64；默认权限码按业务类型分为 `platform`、`resource`、`identity`、`audit`、`monitor`
- `description` 可选，最大长度 255
- `code` 全局唯一
- 停用权限码后，`menu-route` 保存时不允许继续引用该权限码
- 系统监控权限码：`system:monitor:online-user:query`、`system:monitor:online-user:kick`、`system:monitor:service:query`
