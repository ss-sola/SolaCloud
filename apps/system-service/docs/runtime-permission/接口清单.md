# 接口清单

## `GET /api/system/runtime-permissions/current`

读取当前运行时权限。

查询参数：

- `accountId`：可选，指定后按该账号预览运行态；未传时优先读取当前 session 账号

返回字段：

- `account`
- `roleCodes`
- `menuTree`

说明：运行态权限码只用于服务端内部过滤和校验，不在当前接口中返回。

当既没有 `accountId`，也没有当前 session 账号时，返回 `undefined`。

## `POST /api/system/runtime-permissions/check`

校验指定账号是否具备一组权限码。

请求体字段：

- `accountId`
- `permissionCodes: string[]`

返回字段：

- `allowed`
- `missingPermissionCodes`

## `POST /api/system/runtime-permissions/refresh`

手动刷新运行时缓存。

查询参数：

- `accountId`：可选，传入时只刷新指定账号；未传时清空全部缓存
