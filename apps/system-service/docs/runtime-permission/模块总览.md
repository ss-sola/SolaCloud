# runtime-permission 模块总览

## 模块职责

运行时权限模块负责按统一账号主体聚合启用角色与可见菜单树，并提供服务端权限校验与手动刷新入口。权限码仍作为内部过滤与校验依据，但不作为运行态预览响应字段返回。

## 当前定位

- 作为前后台统一账号主体的正式运行时权限输出入口
- 支持当前会话账号或指定账号 ID 预览运行态
- 只基于 `accountId`、`sys_account_role`、角色权限和菜单权限码配置聚合，不再读取 `userId` 或 `sys_user_role`

## 核心入口

- 控制器：`apps/system-service/src/modules/account/controller/runtime-permission.controller.ts`
- 服务：`apps/system-service/src/modules/account/service/runtime-permission.service.ts`
- 账号服务联动：`apps/system-service/src/modules/account/service/account.service.ts`
- 菜单树工具：`apps/system-service/src/modules/menu-route/menu-route.util.ts`

## 对外能力

- 查询当前账号运行时权限
- 按账号 ID 预览运行时权限
- 校验账号是否具备指定权限码集合
- 手动刷新单账号或全量运行时缓存
