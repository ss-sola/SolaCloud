# 接口清单

## 管理账号

### `GET /api/system/accounts/overview`

返回账号模块总览，包括服务名、账号总数、能力列表与头像上传配置。

`avatarUpload` 字段：

- `uploadUrl`：头像上传地址，默认 `http://localhost:3300/api/file/upload`。
- `scene`：上传场景，默认 `account`。
- `businessType`：上传业务类型，固定为 `account-avatar`。
- `isTemporary`：头像文件固定为 `false`，避免临时文件清理误删。

### `GET /api/system/accounts`

查询账号列表。

查询参数：

- `keyword`：按账号名、显示名、备注模糊过滤
- `isEnabled`：按启停状态过滤

### `GET /api/system/accounts/options`

返回启用账号轻量选择项，用于通知发送等跨模块下拉、绑定场景，不复用管理分页接口。

返回字段：

- `id`
- `accountName`
- `displayName`

访问权限：`system:account:manage` 或 `system:notification:manage`

### `GET /api/system/accounts/item?id=...`

查询单个账号详情。

### `POST /api/system/accounts`

新增账号。

请求体字段：

- `accountName`
- `displayName`
- `password`
- `isEnabled`
- `avatarUrl`
- `remark`

### `PUT /api/system/accounts/item?id=...`

更新账号基础信息，支持同步更新可选头像 URL。头像文件上传完成后，将文件服务返回的 `url` 作为隐藏的 `avatarUrl` 保存；账号管理页不展示头像地址文本，账号表不保存文件 ID。基础信息更新不会让当前登录态失效。

### `DELETE /api/system/accounts/item?id=...`

删除账号，并清理账号角色关系。

## 密码与角色

### `PUT /api/system/accounts/password?id=...`

重置账号密码，并清理失败次数与锁定状态；该操作会递增账号状态版本，让旧 session 失效，需要重新登录。

### `GET /api/system/accounts/roles?id=...`

返回指定账号当前绑定的角色编码列表。

### `PUT /api/system/accounts/roles?id=...`

保存指定账号的角色编码集合。

请求体字段：

- `roleCodes: string[]`
