# account 模块总览

## 模块职责

账号模块负责维护前后台统一账号主体、账号启停、密码重置、账号与角色绑定，并为登录态、运行时权限、通知和审计提供账号基础数据。

## 当前定位

- 作为 `system-service` 身份访问底座的核心入口
- 管理 `sys_account` 与 `sys_account_role` 两类数据
- 前台用户和后台管理用户都使用 `account` 作为统一登录主体
- 对登录态输出统一账号主体结构
- 为运行时权限聚合、通知和审计提供账号、角色来源

## 核心入口

- 控制器：`apps/system-service/src/modules/account/controller/account.controller.ts`
- 服务：`apps/system-service/src/modules/account/service/account.service.ts`
- 实体：`apps/system-service/src/modules/account/entity/account.entity.ts`
- 关系实体：`apps/system-service/src/modules/account/entity/account-role.entity.ts`
- 表单：`apps/system-service/src/modules/account/form/*.ts`
- 常量：`apps/system-service/src/modules/account/account.constants.ts`

## 数据模型

- 账号表：`sys_account`，前台用户和后台管理用户共用该主体
- 账号角色关系表：`sys_account_role`，作为唯一角色绑定关系
- 关键字段：
  - `accountName`：登录名与展示主标识
  - `displayName`：展示名称
  - `avatarUrl`：头像 URL，可为空
  - `passwordHash`：密码摘要
  - `isEnabled`：账号是否启用
  - `failedLoginCount`：连续失败次数
  - `lockedUntil`：锁定截止时间
  - `statusVersion`：会话失效版本号

## 对外能力

- 账号总览查询
- 账号列表查询
- 账号新增、编辑、删除
- 密码重置
- 按账号维护角色集合
- 查询账号当前角色编码
