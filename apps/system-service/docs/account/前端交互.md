# 前端交互

## 访问入口

- 页面模块：管理账号

## 页面职责

账号管理页负责组织账号与角色绑定相关接口，覆盖以下能力：

- 查看账号总览
- 按关键词、启停状态筛选账号
- 新增 / 编辑账号基础信息
- 上传账号头像并保存头像 URL
- 删除账号
- 重置密码
- 维护账号角色绑定

## 对接接口

- `GET /api/system/accounts/overview`
- `GET /api/system/accounts`
- `GET /api/system/accounts/item?id=...`
- `POST /api/system/accounts`
- `PUT /api/system/accounts/item?id=...`
- `DELETE /api/system/accounts/item?id=...`
- `PUT /api/system/accounts/password?id=...`
- `PUT /api/system/accounts/roles?id=...`
- `GET /api/system/roles/options`

## 页面交互说明

- 顶栏提供刷新账号与新增账号入口
- 账号列表支持按 ID、账号名、显示名、最近登录、更新时间排序
- 账号列表的显示名列只展示名称，不展示备注描述
- 账号列表展示头像；未配置头像时使用显示名或账号名首字作为 fallback
- 新增 / 编辑账号共用一个 modal，页面只展示头像预览和上传控件，不展示头像 URL 文本
- 头像上传使用账号总览接口返回的 `avatarUpload` 配置，写入文件表的 `businessType` 为 `account-avatar`，账号表只保存返回的 URL
- 角色绑定使用独立 modal，按角色选项列表勾选保存，角色编码、名称支持本地排序
- 密码重置使用独立 modal，保存后自动刷新列表
- 当前登录人信息、头像与登出入口已迁移到全局顶部 header
