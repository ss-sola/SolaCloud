# 接口清单

## 路由前缀

- 全局前缀：`/api`
- 模块前缀：`/system/operation-logs`

## 接口列表

- `GET /api/system/operation-logs/overview`：获取模块总览
- `GET /api/system/operation-logs`：按条件查询操作日志

## 查询参数

- `module`：模块名，可选
- `action`：动作名，可选
- `targetType`：目标类型，可选
- `operator`：操作人，可选

## 查询规则

- 所有查询参数均通过 query 传递
- 列表默认按 `id DESC` 返回
- 当前版本不支持编辑和删除日志
- 日志查询定位于后台排查，不扩展为重型审计平台
