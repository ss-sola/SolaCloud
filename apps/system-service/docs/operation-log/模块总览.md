# operation-log 模块总览

## 模块职责

操作日志模块负责沉淀 system-service 基础资源写操作的留痕数据，为日常排查和运维提供轻量可查的审计入口。

## 当前定位

- 作为 `system-service` 的基础支撑层模块之一
- 记录 dictionary、menu-route、permission、role 的新增、更新、删除行为
- 提供只读查询能力，不承担审批、回滚或差异比对

## 核心入口

- 控制器：`apps/system-service/src/modules/operation-log/controller/operation-log.controller.ts`
- 服务：`apps/system-service/src/modules/operation-log/service/operation-log.service.ts`
- 实体：`apps/system-service/src/modules/operation-log/entity/operation-log.entity.ts`
- 表单：`apps/system-service/src/modules/operation-log/form/*.ts`

## 数据模型

- 表名：`sys_operation_log`
- 存储：PostgreSQL
- 关键字段：
  - `module`：来源模块
  - `action`：执行动作
  - `targetType`：目标类型
  - `targetId`：目标标识
  - `summary`：摘要文案
  - `operator`：操作人

## 对外能力

- 总览查询
- 列表查询
- 按模块过滤
- 按动作过滤
- 按目标类型过滤
- 按操作人过滤
