# 前端交互

## 访问入口

- 页面模块：操作日志查询

## 页面职责

操作日志页负责把留痕查询接口组织成可直接排查的后台页面，覆盖以下能力：

- 查看模块总览
- 按模块、动作、目标类型、操作人筛选日志
- 查看最近资源变更摘要

## 对接接口

- `GET /api/system/operation-logs/overview`
- `GET /api/system/operation-logs`

## 页面交互说明

- 页面初始化时拉取总览和日志列表
- 查询区支持按模块、动作、目标类型、操作人组合过滤
- 日志列表支持按 ID、模块、创建时间排序，排序切换后局部刷新列表
- 模块、动作、目标类型展示通过 `common` 命名空间的字典运行态读取，分别使用 `operation-log.module.`、`operation-log.action.`、`operation-log.target-type.` key 前缀；筛选输入保留自由输入以兼容未知日志值
- 日志列表只读，不提供编辑入口
- 列表默认展示最新日志，便于后台快速排查最近改动
