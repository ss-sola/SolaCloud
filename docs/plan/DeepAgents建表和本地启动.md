现有 PostgreSQL 18.3 使用从官方源码编译的 pgvector 0.8.7。在该实例中新建 `nestcloud_local` 和 `solacloud_local`，由各自的非超级用户角色连接。Redis 复用现有的 6379 端口，会话、队列和注册表使用带专用前缀的逻辑库。实际配置和开发账号凭据通过 Git 忽略的本地文件提供。

完整初始化回归用例在现有 PostgreSQL 18 上通过。RAG 正常写入默认命名空间并保持运行，向量距离查询返回预期结果。四个后端和 Vite 前端均在回环地址监听。注册发现、文件列表、知识库列表及真实浏览器的登录、权限加载、刷新和登出均通过。全量测试以单 worker 执行，385 项通过，9 项按用例声明跳过。类型检查和 lint 均通过。
