# lint-staged 暂存区与工作区不一致

- 日期：2026-03-21
- 分类：通用流程 / 提交流程

## 问题内容

工作区中的问题已经修复，但提交时校验仍然失败。

## 触发条件

- 使用 `lint-staged` 对暂存区内容做校验
- 工作区已更新，但暂存区仍保留旧版本内容

## 失败点

- 只检查了工作区，没有先核对 staged diff
- 误以为校验工具异常，实际是提交内容与本地内容不一致

## 解决方式

- 提交失败时先检查暂存区 diff
- 确认暂存区是否已经包含最新修复内容
- 必要时重新暂存后再执行提交校验

## 后续预防

- 遇到 pre-commit 结果异常，先确认“工作区内容”和“暂存区内容”是否一致
- 将 staged diff 核对作为提交前排查的固定步骤
