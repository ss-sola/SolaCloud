# 根级 ESLint 配置半迁移问题

- 日期：2026-03-21
- 分类：通用基础设施 / 工具链配置

## 问题内容

删除子项目 `eslint.config.mjs` 后，根级 `eslint.config.mjs` 被回退为空文件，导致 lint 链路进入半迁移状态。

## 触发条件

- 正在将 ESLint 配置从子项目收敛到根目录
- 只回退了部分文件，没有同时校验执行脚本与子项目清理状态

## 失败点

- 根配置、执行脚本、子项目配置清理没有保持一致
- 导致仓库处于“看似已迁移，实际不可用”的中间状态

## 解决方式

- 在配置收敛场景下，联动检查：
  - 根级配置是否有效
  - 根脚本是否已切换到新入口
  - 子项目旧配置是否清理完成
- 避免只恢复其中一部分文件

## 后续预防

- 基础工具链迁移必须按链路验证，不做局部回退
- 配置收敛类改动完成后，应从“入口脚本 -> 根配置 -> 子项目”整体回读一次
