# SDK 新增编译文件未被业务服务加载

使用 pnpm 的本地目录依赖时，业务服务从自己的依赖树加载 SDK 安装副本。SDK 增加模块后，如果只在 SDK 目录构建，消费方的旧副本可能缺少 `config-snapshot.util` 等新文件，启动时报 `MODULE_NOT_FOUND`。

先在相邻的 NestCloud-Sdk 执行 `pnpm build`，再在消费项目执行 `pnpm install --force --frozen-lockfile` 更新副本。在实际业务服务目录运行以下两项检查，分别确认实际入口和最终模块加载结果。

```sh
node -p "require.resolve('@nest-cloud/sdk')"
node -e "require('@nest-cloud/sdk')"
```
