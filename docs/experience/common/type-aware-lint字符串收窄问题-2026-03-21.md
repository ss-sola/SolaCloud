# type-aware lint 下的字符串收窄问题

- 日期：2026-03-21
- 分类：通用代码规范 / 类型系统

## 问题内容

在 type-aware lint 场景下，直接对 `unknown` 或 `Record<string, unknown>` 字段做 `String(...)` 转换，引发 `no-base-to-string` 规则报错。

## 触发条件

- 处理外部配置、请求体或第三方回调数据
- 未先做类型收窄，直接进入字符串化

## 失败点

- 默认把外部输入当成可安全转字符串的值
- 忽略了 type-aware lint 对不明确类型值的约束

## 解决方式

- 对 `unknown` 与弱类型对象字段先做显式类型收窄
- 只有在确认值类型后，再进行字符串转换或格式化

## 后续预防

- 外部输入统一先做类型判断再做转换
- 写辅助转换逻辑时，优先复用可复查的收窄流程，而不是直接 `String(...)`
